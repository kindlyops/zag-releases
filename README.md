# zag releases

Public release channel for [zag](https://github.com/kindlyops/zag) (source is private).

- **Releases** hold `Zag-<version>.zip` (the menubar app), `zag-darwin-arm64` (the CLI),
  `zag-bundle-darwin-arm64.tar.gz` (the Bifrost bundle) and `SHA256SUMS`, all attested.
- The `gh-pages` branch serves the Sparkle appcast at
  `https://kindlyops.github.io/zag-releases/appcast.xml`.

`zag pull` downloads bundles from here without a token.
